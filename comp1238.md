# COMP1238 - Midterm Review

## Week 1 - History of Text and Writing
- The oldest known writing is **cuneiform** (Mesopotamia, ~3000 BC). It used a **base-60** number system, which is why we have 60 seconds and 360 degrees.
- **Gutenberg** (~1455) created the printing press with **movable metal type**, making books much cheaper.
- Printing terms: **typeface** vs **font**, **serif** vs **sans-serif**, and **uppercase/lowercase** (from the upper and lower cases where type was stored).
- Typewriters gave us the **carriage return** and **monospace fonts**, still used for writing code.

## Week 2 - Text and Numbers in Computers
- **Bit** = 0 or 1, **byte** = 8 bits. One byte has 256 values: 0 to 255 (unsigned) or -128 to 127 (signed).
- **Volatile vs non-volatile memory:** RAM is fast but loses data when powered off; HDDs and SSDs keep data.
- Converting between bases (binary, decimal, hexadecimal) and their prefixes `0b`, `0o`, `0x`. Example: `01010101` = 85, `0x1F` = 31.
- **ASCII:** 'A' = 65, space = 32, '0' = 48. Control codes: 10 = Line Feed, 13 = Carriage Return.
- **Text files vs binary files:** a binary file opened in a text editor looks like gibberish.

## Week 3 - Structure of Text
- A **markup language** adds structure or formatting to text (Markdown, HTML, XML, YAML).
- Markdown syntax: `#` for headings, `*` or `_` for italic, `**` for bold, `-` for bullet points.
- **JSON** uses `{}` for objects and `[]` for arrays; **XML** uses tags. **Serialization** = converting data into text to store or send it.
- **Escaping** special characters: `\#` in Markdown, `\"` in Python, `&lt;` in HTML.
- **Tim Berners-Lee** created HTML at **CERN**. Rendering engines: Blink, WebKit, Gecko.

## Week 4 - Text Editors and Keyboards
- **Word processor vs text editor:** code is always written in a text editor or an IDE.
- **IDE** = text editor + development tools (debugger, compiler, version control).
- **Vim:** to quit without saving, type `:q!`.
- Shortcuts: `Ctrl+F` find, `Ctrl+H` replace, `Ctrl+D` multiple cursors. **Regex** basics: `\d` digit, `.` any character, `^` start of line, `$` end of line.
- **QWERTY vs Dvorak**, and why learning **touch typing** is worth it.

## Week 5 - Command Line Interfaces
- Parts of a command: prompt, command, argument, and options (`-l` short, `--long` long).
- Basic commands: `ls`, `ls -l`, `ls -a`, `pwd`, `cd ..`, `cat`, `less`, `cp`, `mv`, `mkdir`, `man`.
- `>` overwrites a file, `>>` appends to it, and `|` (pipe) sends one command's output to another, e.g. `ls -l | wc -l`.
- **SSH** connects securely to a remote server (`ssh user@server`); `scp` and `sftp` transfer files.
- **Unix philosophy:** small programs that do one thing well and can be combined.
